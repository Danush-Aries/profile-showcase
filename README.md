# profile-showcase

Live profile hub for **Dhanush Shankar — AI & Security Engineer**.

Auto-pulls GitHub stats, featured repos, and totals straight from the GitHub API on every visit. Zero build step, vanilla HTML/CSS/JS, deployable on GitHub Pages.

## Run locally
```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy
Push to `main`. Site serves from the root via GitHub Pages.
